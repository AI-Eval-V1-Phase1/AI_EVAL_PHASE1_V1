# Vendor COTS Assessment – Multistep Form

This folder contains the Vendor COTS (Commercial Off-The-Shelf) multistep assessment UI, aligned with the vendor self-attestation pattern and driven by schema/options constants.

## Changelog (Vendor COTS multistep form)

- **New:** `frontend/src/constants/vendorCotsFormSchema.ts` (190 lines) – Form schema with Label, Input Type, Options/Validation key, Required per field.
- **New:** `frontend/src/constants/vendorCotsOptions.ts` (139 lines) – Options for select/multiselect (industry sector, budget, timeline, product features, implementation approach, customization, integration complexity, regulatory, data sensitivity, risk tolerance, customer-specific risks).
- **New:** `frontend/src/Components/pages/Assessments/VendorCOTS/VendorCotsDynamicStep.tsx` (169 lines) – Dynamic step component by input type; uses schema + options.
- **Updated:** `frontend/src/Components/pages/Assessments/VendorCOTS/VendorCOTSMain.tsx` – Steps 0–4 now use `VendorCotsDynamicStep` and `VENDOR_COTS_FORM_SECTIONS`; step validation (required fields) with `validationAttemptedSteps` and `disabledSteps`; empty multiselects sent as `"[]"` in submit/save-draft.
